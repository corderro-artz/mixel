# mixel Web Front End Implementation Plan (Plan 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `Mixel.Web` — a Blazor WebAssembly PWA that exposes the full `Mixel.Core` feature set (depth, voxel-size, format, pivot, batch) with a live 3D preview, 14 themes (Vaporsoft Dark default), single-screen UI, and offline/local-first operation.

**Architecture:** Standalone Blazor WebAssembly PWA referencing `Mixel.Core` (compiled to WASM, pure-managed, no native deps). All extrusion runs in-browser via the existing Core pipeline; one small Core addition (`ExtrudeToMemory`) returns glTF files as byte arrays so the web app never touches a filesystem. A vendored `<model-viewer>` web component renders the generated `.glb`. JS interop handles file download, model `src`, theme persistence, and `prefers-color-scheme`.

**Tech Stack:** .NET 10 Blazor WebAssembly (PWA template), `Mixel.Core` (net8.0, referenced), SharpGLTF (already in Core), `<model-viewer>` (vendored), System.IO.Compression (zip), xUnit (+ bUnit best-effort) for tests.

## Global Constraints

- **`Mixel.Web` targets `net10.0`** (the installed SDK's Blazor WASM template TFM); it references `Mixel.Core` (net8.0) — a net10 app running a net8.0 library is supported. Do NOT retarget `Mixel.Core`.
- **Standalone Blazor WebAssembly PWA** (`dotnet new blazorwasm --pwa`). NOT a Blazor Web App (PWA option is standalone-WASM only).
- **Local-first / offline / zero network:** no server calls, no CDN, no telemetry, no account. `<model-viewer>` and all assets are vendored locally and precached by the service worker. Verify offline works after `dotnet publish`.
- **Full feature parity with the CLI:** depth (int ≥1, default 1), voxel-size (float >0, default 1.0), format (glb | gltf | gltf-embedded, default glb), pivot (bottom-center | center | min-corner, default bottom-center), batch (multiple files), recursive is N/A in-browser (folder picker yields a flat file list — omit the recursive flag in the UI).
- **14 themes, Vaporsoft Dark is the default.** Exact brand hexes (from vaporsoft.dev live CSS):
  - Vaporsoft Dark (default): bg `#07080b`, text `#f2ede6`, accent `#a11f31`, border `rgba(242,237,230,.14)`.
  - Vaporsoft Light: bg `#f4efe8`, text `#121318`, accent `#a11f31`, border `rgba(18,20,24,.12)`.
  - 6 dark alternates: Midnight `#6366f1`/`#0f1115`, Carbon `#d4d4d4`/`#0e0e0e`, Forest `#34d399`/`#0c1410`, Ember `#f59e0b`/`#14100c`, Synthwave `#ec4899`/`#16091f`, Ocean `#22d3ee`/`#08141c`.
  - 6 light alternates: Daylight `#2563eb`/`#ffffff`, Linen `#b45309`/`#faf6ef`, Mint `#059669`/`#f2faf5`, Rose `#db2777`/`#fdf2f6`, Slate `#0ea5e9`/`#f1f5f9`, Sand `#ca8a04`/`#f7f1e6`.
- **Theme selection persists in `localStorage`**; `prefers-color-scheme` only influences the first-run pick between the two brand themes (still defaults toward Vaporsoft Dark).
- net10/net8 only; SharpGLTF + StbImage are pure-managed (WASM-safe). No new native dependencies.
- Commit after every task with Conventional Commit messages.

## Testing note (scope)

The spec (§13.6) named an automated Playwright offline smoke. Automated browser E2E against a published PWA is fragile in this environment, so this plan covers behavior with **xUnit** (pure services: theme registry, extrusion, zip, settings mapping) and **bUnit where it runs cleanly** (component render/binding). Install/offline/preview are a **documented manual acceptance checklist** (Task 8). This is a deliberate, noted deviation from §13.6.

- [ ] **Step 4: Add `WriteToMemory` to `GltfWriter.cs`**

`BuildModel(Mesh, byte[])` already exists (used by `WriteGlbBytes`/`Write`). Add this public method to the `GltfWriter` class (keep existing members):

```csharp
public static IReadOnlyList<MixelFile> WriteToMemory(
    Mesh mesh, byte[] pngTexture, GltfFormat format, string baseName)
{
    var model = BuildModel(mesh, pngTexture);

    switch (format)
    {
        case GltfFormat.Glb:
            return new[] { new MixelFile($"{baseName}.glb", model.WriteGLB().ToArray()) };

        case GltfFormat.GltfEmbedded:
        {
            // Single self-contained .gltf with base64-embedded buffers + image.
            var dict = model.WriteToDictionary(baseName, new WriteSettings
            {
                ImageWriting = ResourceWriteMode.EmbeddedAsBase64,
                MergeBuffers = true,
            });
            // Embedded mode yields a single .gltf entry.
            return dict.Select(kv => new MixelFile(kv.Key, kv.Value.ToArray())).ToList();
        }

        case GltfFormat.Gltf:
        default:
        {
            var dict = model.WriteToDictionary(baseName);
            return dict.Select(kv => new MixelFile(kv.Key, kv.Value.ToArray())).ToList();
        }
    }
}
```

> Note: verify the `WriteToDictionary` overloads in SharpGLTF 1.0.6. If `WriteToDictionary(string, WriteSettings)` does not exist, use the overload that does: either `model.WriteToDictionary(baseName)` after configuring a `WriteContext`, or write embedded via `WriteContext.CreateFromDictionary(...)` with `ImageWriting = EmbeddedAsBase64`. The tests pin the contract (Glb→1 file `.glb`; GltfEmbedded→exactly 1 file `.gltf`; Gltf→≥2 files incl `.gltf`). Make whichever real API satisfies those assertions; do not weaken the tests. If embedded cannot be produced as a single file in 1.0.6, report DONE_WITH_CONCERNS describing the limitation rather than silently emitting satellites for the embedded case.

Ensure these usings are present at the top of `GltfWriter.cs` (add any missing): `using System.Linq;` and `using SharpGLTF.Schema2;` (already present).

Create `src/Mixel.Web/wwwroot/js/mixel.js`:

```javascript
window.mixel = {
  _urls: new WeakMap(),
  setModelSrc: function (el, bytes) {
    if (!el) return;
    const old = this._urls.get(el);
    if (old) URL.revokeObjectURL(old);
    const blob = new Blob([bytes], { type: "model/gltf-binary" });
    const url = URL.createObjectURL(blob);
    this._urls.set(el, url);
    el.setAttribute("src", url);
  },
  downloadFile: function (name, bytes) {
    const blob = new Blob([bytes], { type: "application/octet-stream" });
    const url = URL.createObjectURL(blob);
    const a = document.createElement("a");
    a.href = url; a.download = name;
    document.body.appendChild(a); a.click(); a.remove();
    URL.revokeObjectURL(url);
  },
  saveTheme: function (id) { try { localStorage.setItem("mixel-theme", id); } catch (e) {} },
  loadTheme: function () { try { return localStorage.getItem("mixel-theme"); } catch (e) { return null; } },
  prefersDark: function () {
```

```csharp
using System.IO.Compression;
using Mixel.Core;

namespace Mixel.Web.Services;

public sealed record BatchOutcome(string Input, bool Success, string? Error);

public static class ExtrusionService
{
    public static byte[] PreviewGlb(byte[] png, ExtrudeSettings s)
    {
        var opts = s.ToOptions(png) with { Format = GltfFormat.Glb };
        return Extruder.ExtrudeGlb(opts);
    }

    public static IReadOnlyList<MixelFile> Single(byte[] png, string baseName, ExtrudeSettings s)
        => Extruder.ExtrudeToMemory(s.ToOptions(png), baseName);

    public static byte[] BatchZip(
        IReadOnlyList<(string name, byte[] png)> inputs, ExtrudeSettings s,
        out IReadOnlyList<BatchOutcome> outcomes)
    {
        var results = new List<BatchOutcome>(inputs.Count);
        using var ms = new MemoryStream();
        using (var zip = new ZipArchive(ms, ZipArchiveMode.Create, leaveOpen: true))
        {
            foreach (var (name, png) in inputs)
            {
                var baseName = Path.GetFileNameWithoutExtension(name);
                try
                {
                    foreach (var file in Extruder.ExtrudeToMemory(s.ToOptions(png), baseName))
                    {
                        var entry = zip.CreateEntry(file.Name, CompressionLevel.Optimal);
                        using var es = entry.Open();
                        es.Write(file.Bytes, 0, file.Bytes.Length);
                    }
                    results.Add(new BatchOutcome(name, true, null));
                }
                catch (Exception ex)
                {
                    results.Add(new BatchOutcome(name, false, ex.Message));
                }
            }
        }
        outcomes = results;
        return ms.ToArray();
    }
}
```

```razor
    private readonly ExtrudeSettings _settings = new();

                await Js.DownloadFileAsync(name + ".zip", zip);

            var zip = ExtrusionService.BatchZip(
                _files.Select(f => (f.name, f.bytes)).ToList(), _settings, out _);
            await Js.DownloadFileAsync("mixel-export.zip", zip);
        }
```
